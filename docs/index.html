promofinder · live demo

Find the promos in a microdrama screenplay

The tool reads timestamped screenplays and finds clips that work as ads: 20–60 seconds, a hook in the first 3 seconds, a cliffhanger at the end, and clear to someone who has never seen the show. Then it ranks which to post first.

What you're looking at

The show is made up. Night Line is a 4-episode, 6-minute microdrama written for this demo, in the same screenplay format as the confidential 50-episode pack the tool was built on. That pack, and every result on it, stays private.

The viewer is the tool's unedited output on the demo, with a small local AI judge (qwen3.5 4B through Ollama, no API key). It shows the promos ranked, a posting plan, and a timed transcript of every part, with hook and cliffhanger marked. Approve or reject each promo and export your decisions as CSV.

The demo shows how the tool works. It is not evidence of quality, because the same person wrote the show and the tool. The quality checks were run on the real pack.

How it works

  • Code decides time; the model decides taste. A parser gives every shot, action and spoken line an ID and exact times. Code lists every legal window and never cuts inside a spoken line.
  • The model rates candidates by naming block IDs only, so it can't invent a timestamp or a quote.
  • Eight hard checks gate every promo: length, hook timing, cliffhanger placement, parts, order, episode bounds, safe cuts and real IDs.
  • The ranking spreads promos across episodes and ends in a posting plan: premise first, then escalation, then payoffs.
