# Input

Put a screenplay pack here: one UTF-8 `.txt` file per episode, named like `episode-001-Episode 123.txt`, in the format described in [`../schema/EPISODE_FORMAT.md`](../schema/EPISODE_FORMAT.md).

The original pack is confidential, so git ignores everything in this folder except this note. To try the tool without a pack, use the made-up show in [`../demo/Input/`](../demo/Input/).
